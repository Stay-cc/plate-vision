## 1. M1 交付范围

本阶段完成了不依赖 Qt 的完整命令行识别链路：

```text
图片/视频文件
    -> OpenCV 数据源
    -> CaptureService
    -> BoundedLatestQueue
    -> RecognitionPipeline
    -> 模拟车牌检测
    -> 透视矫正
    -> 模拟字符识别
    -> 车牌格式校验
    -> 简单 IOU 跟踪
    -> 标注视频 + JSON 报告
```

本阶段不包含真实 YOLO/LPRNet 模型、Qt 界面、SQLite 持久化和多帧稳定文本投票。

## 3. 关键实现

### 有界最新帧队列

- 采集速度高于推理速度时丢弃最旧帧；
- 通过条件变量唤醒识别线程；
- `close()` 唤醒所有等待者并支持有界时间退出；
- 统计累计丢帧数量。

### 采集服务

- 独立线程读取 `IVideoSource`；
- 为每帧分配序号、流 ID 和接收时间戳；
- 数据源结束后自动关闭帧队列；
- 停止时等待采集线程退出。

### 识别流水线

- 检测、矫正、识别、跟踪分阶段计时；
- 车牌经过格式校验后才标记为有效；
- 跟踪目标累计命中后确认；
- 不依赖 Qt、数据库或具体 ONNX 模型。

### CLI

支持以下能力：

- `--generate-sample` 生成 1080p 合成测试视频；
- `--input` 读取图片或视频；
- `--output-video` 输出带标注 MP4；
- `--output-json` 输出逐帧结果；
- `--queue-capacity` 调整有界队列容量；
- `--plate` 和 `--color` 配置模拟识别结果；
- `--max-frames`、`--fps` 控制测试运行。

## 6. 当前限制

- 检测器返回固定的中心车牌区域；
- 识别器直接返回配置的车牌文本；
- 跟踪器只使用 IOU，不包含 ByteTrack 或重识别；
- 还没有稳定文本投票和重复通行记录抑制；
- 还没有 SQLite、截图保存和记录查询；
- 还没有 Qt 桌面界面；
- RTSP 读取失败暂时没有自动重连。
